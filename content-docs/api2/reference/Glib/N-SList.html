Gnome::Glib::SList§

Description§

The N-SList struct is used for each element in the singly-linked list.

Note that this class is mainly used to get the data from a list returned by e.g. a widget. Raku has smart types to the work much easier.

Record N-SList§

class N-SList:auth<github:MARTIMM>:api<2> is export is repr('CStruct') {

  has gpointer $.data;
  has N-SList $.next;
}
Code
  • data; holds the element's data, which can be a pointer to any kind of data, or any integer value using the Type Conversion Macros
  • next; contains the link to the next element in the list.

Code

append§

Adds a new element on to the end of the list.

The return value is the new start of the list, which may have changed, so make sure you store the new value.

Note that .append() has to traverse the entire list to find the end, which is inefficient when adding multiple elements. A common idiom to avoid the inefficiency is to prepend the elements and reverse the list when all elements have been added. 

method append ( N-SList $list, gpointer $data --> N-SList )
Code
  • $list; a N-SList.
  • $data; the data for the new element.

Return value; the new start of the N-SList.

concat§

Adds the second N-SList onto the end of the first N-SList. Note that the elements of the second N-SList are not copied. They are used directly. 

method concat ( N-SList $list1, N-SList $list2 --> N-SList )
Code
  • $list1; a N-SList.
  • $list2; the N-SList to add to the end of the first N-SList.

Return value; the start of the new N-SList.

copy§

Copies a N-SList.

Note that this is a "shallow" copy. If the list elements consist of pointers to data, the pointers are copied but the actual data isn't. See .copy-deep() if you need to copy the data as well. 

method copy ( N-SList $list --> N-SList )
Code
  • $list; a N-SList.

Return value; a copy of $list.

copy-deep§

Makes a full (deep) copy of a N-SList.

In contrast with .copy(), this function uses $func to make a copy of each list element, in addition to copying the list container itself. $func, as a Gnome::Glib::T-DoubleIEEE754, takes two arguments, the data to be copied and a $user_data pointer. On common processor architectures, it's safe to pass Nil as $user_data if the copy function takes only one argument. method copy-deep ( N-SList $list, &func, gpointer $user-data --> N-SList )
Code
  • $list; a N-SList.
  • &func; a copy function used to copy every element in the list. Tthe function must be specified with following signature; :( gpointer $src, gpointer $user-data -- gpointer )>.

delete-link§

Removes the node link_ from the list and frees it. Compare this to .remove-link() which removes the node without freeing it.

Removing arbitrary nodes from a singly-linked list requires time that is proportional to the length of the list (ie. O(n)). If you find yourself using .delete-link() frequently, you should consider a different data structure, such as the doubly-linked Gnome::Glib::N-List. 

method delete-link ( N-SList $list, N-SList $link --> N-SList )
Code
  • $list; a N-SList.
  • $link; node to delete.

Return value; the new head of $list.

find-custom§

Finds an element in a N-SList, using a supplied function to find the desired element. It iterates over the list, calling the given function which should return 0 when the desired element is found. The function takes two gconstpointer arguments, the N-SList element's data as the first argument and the given user data. 

method find-custom ( N-SList $list, gpointer $data, &func --> N-SList )
Code
  • $list; a N-SList.
  • $data; user data passed to the function.
  • &func; the function to call for each element. It should return 0 when the desired element is found. Tthe function must be specified with following signature; :( gpointer $a, gpointer $b -- gint )>.

Return value; the found N-SList element, or Nil if it is not found.

foreach§

Calls a function for each element of a N-SList.

It is safe for $func to remove the element from $list, but it must not modify any part of the list after that element. 

method foreach ( N-SList $list, &func, gpointer $user-data )
Code
  • $list; a N-SList.
  • &func; the function to call with each element's data. Tthe function must be specified with following signature; :( gpointer $data, gpointer $user-data ).
  • $user-data; user data to pass to the function.

free§

Frees all of the memory used by a N-SList. The freed elements are returned to the slice allocator.

If list elements contain dynamically-allocated memory, you should either use .free-full() or free them manually first.

It can be combined with g_steal_pointer() to ensure the list head pointer is not left dangling:

method free ( N-SList $list )
Code
  • $list; the first link of a N-SList.

free-full§

Convenience method, which frees all the memory used by a N-SList, and calls the specified destroy function on every element's data. $free_func must not modify the list (eg, by removing the freed element from it).

It can be combined with g_steal_pointer() to ensure the list head pointer is not left dangling ­— this also has the nice property that the head pointer is cleared before any of the list elements are freed, to prevent double frees from $free_func: 

method free-full ( N-SList $list, &free-func )
Code
  • $list; the first link of a N-SList.
  • &free-func; the function to be called to free each element's data. Tthe function must be specified with following signature; :( gpointer $data ).

remove§

Removes an element from a N-SList. If two elements contain the same data, only the first is removed. If none of the elements contain the data, the N-SList is unchanged. 

method remove ( N-SList $list, gpointer $data --> N-SList )
Code
  • $list; a N-SList.
  • $data; the data of the element to remove.

Return value; the new start of the N-SList.

remove-all§

Removes all list nodes with data equal to $data. Returns the new head of the list. Contrast with .remove() which removes only the first node matching the given data. 

method remove-all ( N-SList $list, gpointer $data --> N-SList )
Code
  • $list; a N-SList.
  • $data; data to remove.

Return value; new head of $list.

remove-link§

Removes an element from a N-SList, without freeing the element. The removed element's next link is set to Nil, so that it becomes a self-contained list with one element.

Removing arbitrary nodes from a singly-linked list requires time that is proportional to the length of the list (ie. O(n)). If you find yourself using .remove-link() frequently, you should consider a different data structure, such as the doubly-linked Gnome::Glib::N-List. 

method remove-link ( N-SList $list, N-SList $link --> N-SList )
Code
  • $list; a N-SList.
  • $link; an element in the N-SList.

Return value; the new start of the N-SList, without the element.

sort§

Sorts a N-SList using the given comparison function. The algorithm used is a stable sort. 

method sort ( N-SList $list, &compare-func --> N-SList )
Code
  • $list; a N-SList.
  • &compare-func; the comparison function used to sort the N-SList. This function is passed the data from 2 elements of the N-SList and should return 0 if they are equal, a negative value if the first element comes before the second, or a positive value if the first element comes after the second.. Tthe function must be specified with following signature; :( gpointer $a, gpointer $b -- gint )>.

Return value; the start of the sorted N-SList.

sort-with-data§

Like .sort(), but the sort function accepts a user data argument. 

method sort-with-data ( N-SList $list, &compare-func, gpointer $user-data --> N-SList )
Code

  • &compare-func; comparison function. Tthe function must be specified with following signature; :( gpointer $a, gpointer $b, gpointer $user-data -- gint )>.
  • $user-data; data to pass to comparison function.

Return value; new head of the list.
