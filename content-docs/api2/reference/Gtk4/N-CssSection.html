Description§

Defines a part of a CSS document.

Because sections are nested into one another, you can use method .get-parent() to get the containing region.

get-file§

Gets the file that $section was parsed from.

If no such file exists, for example because the CSS was loaded via .load-from-data() in class Gnome, then undefined is returned. 

method get-file (--> N-Object )
Code

Return value; the Gnome::Gio::File from which the section was parsed.

get-parent§

Gets the parent section for the given section.

The parent section is the section that contains this section. A special case are sections of type GTK_CSS_SECTION_DOCUMENT. Their parent will either be undefined if they are the original CSS document that was loaded by .load-from-file() in class Gnome or a section of type GTK_CSS_SECTION_IMPORT if it was loaded with an ` $import` rule from a different file. 

method get-parent (--> N-Object )
Code

Return value; the parent section.
